# RPG Party Creator - Class Project

## Description

This program creates various hero classes and prints out their information and an attack message.

## How to Run

1. Download all files from the repository
2. In VS Code (with Python installed) open main.py
3. Run the code

## Example input/output

- Input: none
- Output: 
  === RPG PARTY BATTLE SIMULATOR ===
  
  Hero: Ocean (HP: 80)
  Ocean have sanctioned you in the name of justice!
  
  Hero: Alex (HP: 100)
  Alex: Shield activated
  
  Hero: Frank (HP: 60)
  Frank uses a basic attack!
  
  Hero: Mr.L (HP: 80)
  Mr.L casts Fireball using 100 mana!
  
  Hero: Tommy (HP: 120)
  Tommy unleashes a Power Slash using 50 rage!
